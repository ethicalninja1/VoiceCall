Privacy & data handling

  • Users agree on sign-up that the admin can see their name, ID, email/mobile, IP address, device and approximate location.
  • Precise GPS is shared only if the user allowed the browser permission, and can be switched off by the user at any time.
  • Passwords are stored as salted scrypt hashes — nobody can read them. Chat text is stored on the server so messages reach offline users; this console never shows message content.
  • Calls, video and in-call chat are peer-to-peer. Users can delete their account; you can export or delete any record.
